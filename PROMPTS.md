# Prodesk IT – Sprint 10:


This file contains the prompts used as references for understanding, developing, reviewing, and improving the Blog API project.

## 1. Project Development

```text
Develop a RESTful Blog API using Node.js, Express.js, MongoDB, and Mongoose.

Include blog post creation, reading, updating, and deletion.
Maintain a clean project structure and write readable code.
```

## 2. Database Integration

```text
Integrate MongoDB with the Express application using Mongoose.

Create User and Post models with appropriate fields and validation.
Handle database connection errors properly.
```

## 3. API Development

```text
Create REST API routes for managing blog posts.

Implement GET, POST, PUT, and DELETE operations.
Add proper request validation and meaningful response messages.
```

## 4. User Management

```text
Develop user management routes.

Allow users to be created and retrieved.
Validate required fields and handle duplicate email addresses.
```

## 5. Authentication

```text
Create a basic login endpoint for demonstration purposes.

Validate the required email and password fields.
Clearly identify mock authentication and its security limitations.
```

## 6. Error Handling

```text
Implement centralized error handling in the Express application.

Handle invalid requests, database errors, validation errors,
and unavailable routes.
```

## 7. Code Review

```text
Review the complete Blog API project.

Identify bugs, unnecessary code, security issues, and
possible improvements.

Keep the existing project structure wherever possible.
```

## 8. Testing

```text
Prepare API testing cases for all implemented endpoints.

Test successful requests, invalid inputs, missing fields,
invalid IDs, and database errors.

Provide expected status codes and responses.
```

## 9. Documentation

```text
Create clear README documentation for the project.

Include project overview, features, technology stack,
installation instructions, API endpoints, and examples.
```

## 10. Final Verification

```text
Check the complete Blog API project before submission.

Verify dependencies, environment configuration,
database connection, API routes, error handling,
and project documentation.

Do not claim that any test has passed unless it
has actually been executed.
```
